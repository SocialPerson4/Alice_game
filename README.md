# 奇域梦幻漫游录 Alice Game

《奇域梦幻漫游录》是一个五人团队开发的多章节互动视觉小说，以《爱丽丝梦游仙境》为叙事原型，通过对话推进、分支选择、角色状态和章节小游戏呈现爱丽丝在仙境中的成长过程。项目获全国大学生数字媒体科技作品及创意竞赛江苏赛区三等奖。

公开仓库保留可审阅的核心代码。比赛使用的部分图片、音乐、音效和视频由团队成员创作或整理，未随仓库公开，因此当前版本用于代码复现与结构审阅，不等同于完整参赛交付包。

## 功能概览

- 五章节视觉小说流程与章节入口
- 对话状态推进、分支选择、角色反馈和多结局
- 卡牌、时间和棋盘等章节小游戏
- 注册登录与 JWT 身份认证
- 成就、音频偏好、道具与背包接口
- 第五章内心法庭交互、生命值反馈与 Web Audio 音效

## 技术实现

- 前端：HTML、CSS、JavaScript、Web Audio API、Matter.js、dat.GUI
- 后端：Node.js、Express、JWT、bcryptjs
- 数据库：MySQL、连接池、参数化查询、事务、外键与联合唯一索引
- 工程化：环境变量配置、GitHub Actions、Node.js 内置测试框架

## 系统结构

```text
Alice_game/
├── src/                  # Express 服务、身份认证与业务接口
├── public/               # 页面、章节和前端交互代码
│   ├── chapter/          # 五章节与章节小游戏
│   └── js/               # 成就与音频设置模块
├── database/schema.sql   # 统一数据库结构
├── test/                 # 不依赖 MySQL 的基础接口测试
├── scripts/              # 项目结构与敏感信息检查
└── docs/                 # 团队贡献与媒体资源说明
```

前端负责场景、对话、选择和音频交互；Express 提供注册、登录、用户资料、成就、音频设置和道具接口；MySQL 保存用户及相关业务数据。注册流程使用事务完成用户、预置成就和背包初始化，受保护接口通过 Bearer Token 验证用户身份。

## 本地运行

环境要求：Node.js 18+、MySQL 8.x。

```bash
npm install
mysql -u root -p < database/schema.sql
cp .env.example .env
```

编辑 `.env` 后启动：

```bash
set -a
source .env
set +a
npm start
```

浏览器访问 `http://localhost:3000`。

## 测试

```bash
npm run check
npm test
```

当前自动化测试覆盖健康检查、首页静态资源、受保护接口的未授权访问和默认同源 CORS 行为。真实 MySQL 事务、完整登录链路和全部剧情分支尚未纳入自动化测试。

## 安全设计

- JWT 密钥和数据库口令通过环境变量提供，`.env` 不进入版本控制。
- 密码使用 bcrypt 哈希保存，SQL 查询使用参数占位符。
- 默认采用同源访问，仅在配置 `CORS_ORIGIN` 时开放指定来源。
- 成就解锁仅接受服务端预置标识，道具接口校验已知道具。

## 当前边界

- 游戏进度保存在浏览器本地，当前没有 MySQL 游戏进度表。
- JWT 登出主要由客户端删除令牌完成，未实现服务端撤销列表。
- 前端章节仍以较大的 HTML 文件和内联脚本为主，公共逻辑尚未完全组件化。
- 公开版缺少比赛媒体资源，部分场景会使用静默或空白降级。
- 仓库未声明开源许可证，仅用于项目代码展示与审阅。
