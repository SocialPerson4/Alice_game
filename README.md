# 奇域梦幻漫游录（Alice Game）

面向课程实践开发的多章节互动视觉小说。项目以《爱丽丝梦游仙境》为叙事原型，通过网页交互、分支选择和章节小游戏组织剧情，并以 Node.js/Express 与 MySQL 支持账户、成就、音频偏好和道具数据。

> 项目性质：五人课程团队项目。公开仓库保留核心代码并如实标注个人贡献；媒体资源未公开，因此仓库不等同于完整参赛交付包。

## 功能概览

- 五章节视觉小说流程与章节入口
- 剧情对话、选择分支、场景切换和多结局
- 卡牌、时间、棋盘等章节小游戏
- 注册登录与 JWT 身份认证
- 成就、音频偏好、道具与背包接口
- 第五章“内心法庭”式交互、状态反馈与 Web Audio 音效

## 技术栈

- 前端：HTML、CSS、JavaScript、Web Audio API、Matter.js、dat.GUI
- 后端：Node.js、Express、JWT、bcryptjs
- 数据：MySQL、连接池、参数化查询、外键与联合唯一索引
- 工具：Git、Cursor；Gemini/Claude 用于开发期资料整理与叙事发散，运行时不调用模型

## 项目结构

```text
Alice_game/
├── src/                  # Express 服务、业务接口与数据库初始化
├── public/               # 页面、章节和前端脚本（公开版不含媒体）
│   ├── chapter/          # 五章节与小游戏
│   ├── js/               # 成就、音频等前端模块
│   ├── img/              # 本地可选图片（公开版不含媒体文件）
│   └── music/            # 本地可选音乐（公开版不含媒体文件）
├── database/schema.sql   # 与服务端实现一致的统一数据库结构
├── test/                 # 不依赖 MySQL 的基础接口测试
├── scripts/              # 项目结构和敏感信息检查
└── docs/                 # 职责说明、简历表述与答辩准备
```

原始课程工程中的 `node_modules`、IDE 配置、数据库导出文件和固定凭据均未纳入仓库；重复且相互冲突的 SQL 脚本已合并为单一 schema。公开仓库只保留核心代码和文档，图片、音频与视频仍保存在本地课程归档中。第五章道具读取已统一到实际存在的 `/api/items`；当前没有MySQL游戏进度接口。

## 本地运行

环境要求：Node.js 18+、MySQL 8.x。

```bash
npm install
mysql -u root -p < database/schema.sql
cp .env.example .env
```

编辑 `.env` 后，在 bash/zsh 中载入配置并启动：

```bash
set -a
source .env
set +a
npm start
```

浏览器访问 `http://localhost:3000`。基础检查（4项测试不依赖MySQL）：

```bash
npm run check
npm test
```

## 安全与说明

- JWT 密钥和数据库口令仅从环境变量读取，`.env` 不进入版本控制。
- SQL 查询使用参数占位符，密码经 bcrypt 哈希后存储。
- 图片、音乐、音效和视频文件仅保留在本地课程归档中，不随当前公开仓库分发。
- 公开版用于审阅核心实现；运行页面时，涉及原始图片、音频或视频的场景会显示空白或静默降级。媒体边界见 [媒体说明](docs/MEDIA.md)。
- 仓库不声明开源许可证。
- 当前版本定位为课程项目归档与复现，尚未完成生产部署、令牌吊销和完整自动化测试。

## 已知限制

- 前端章节仍以大体量HTML和内联脚本为主，复用性不足。
- JWT登出主要由客户端删除令牌完成，没有服务端撤销列表。
- 公开版缺少媒体资源，不适合作为完整在线演示。
- 尚无MySQL集成测试、完整分支覆盖率和正式部署安全审计。
- 道具获取由客户端事件触发，尚未建立服务端章节进度校验。
