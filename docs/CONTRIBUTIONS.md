# 团队贡献说明

《奇域梦幻漫游录》由五名成员协作完成。团队按照技术开发、章节内容和视觉资源进行分工，并通过统一接口和章节入口完成整合。

## 王禹钦

- 担任技术负责人，负责整体技术方案、核心功能实现和前后端联调。
- 负责第五章页面与交互逻辑，包括场景和对话推进、分支选择、生命值反馈及多结局流程。
- 完成第五章音频接入，使用 Web Audio API 实现交互音效和音量状态管理。
- 参与并整合 Node.js、Express 与 MySQL 模块，完成 JWT 登录鉴权、成就、音频和道具接口及数据库结构。
- 与剧情、美术和其他章节开发成员确定资源规格、接口字段、状态衔接与集成方式。

## 冯依蕊

- 负责第一章内容实现、场景视觉设计和部分剧情整理。
- 参与统一页面视觉风格与背景资源。

## 王智龙

- 负责第二章内容实现。
- 参与后端接口、MySQL 数据库设计和前后端联调。

## 于昂

- 负责第三章内容实现。
- 参与章节入口、页面跳转和整体流程串联。

## 刘伟

- 负责第四章内容实现。
- 参与人物立绘、动态素材和视觉效果制作。

## 协作方式

团队先确定章节边界、共享状态和媒体资源规格，再分别实现页面与素材；集成阶段统一路由、接口和数据库结构，对章节入口、资源路径、身份认证和业务数据进行联调。公开仓库保留核心代码，未公开的媒体资源仍由课程项目组归档。
