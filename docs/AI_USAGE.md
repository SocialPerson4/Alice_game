# AI 辅助使用说明

项目开发中使用了 Cursor，并参考 Gemini、Claude 进行资料整理和叙事创意发散。

## 使用范围

- 查询 Web Audio API、前后端接口和页面交互的实现思路
- 辅助生成重复性代码草稿和定位语法问题
- 对角色动机、剧情分支和伏笔进行发散
- 协助整理注释、项目文档和调试清单

## 人工负责内容

- 确定需求、模块边界和数据结构
- 筛选、修改和整合建议代码
- 完成页面与美术资源适配
- 执行联调、运行验证和问题修正
- 对最终实现及项目陈述负责

答辩时可以直说使用了 AI 辅助工具，重点说明如何验证建议、如何发现不适用内容，以及最终方案为什么这样设计。
