# 职责说明

本页用于统一课程报告、简历和答辩中的项目归属口径。

## 王禹钦个人贡献

1. 第五章前端：实现页面布局、场景与对话推进、选项分支、角色状态反馈及多结局流程。
2. 交互与音频：组织“内心法庭”式剧情交互，接入第五章背景音乐和交互音效。
3. 剧情脚本：负责整体剧本设计，并完成第五章台词、分支和结局的工程化落地。
4. 后端与数据库：与王智龙共同开发 Node.js/Express 与 MySQL 模块，协作完成 JWT 登录鉴权、成就/音频/道具接口、数据表及联调。注册流程使用事务，成就接口只解锁服务端预置定义。
5. 工程协作：使用 Cursor 辅助编码和资料检索，与美术成员对接资源规格、页面状态和交互效果。

## 建议口述

“这是五人课程团队项目。我主要负责第五章前端、音频和剧本设计；后端和数据库由我与王智龙协作完成。我能够重点讲清第五章的状态推进、分支逻辑、Web Audio 音效，以及 JWT 登录和成就/道具接口的实现。其余章节和美术资源由其他成员分工完成。”

## 不建议使用的说法

- “项目全部由我独立开发。”
- “后端采用 Java。”——当前仓库的后端是 Node.js/Express，没有 Java 源码。
- “使用 AI 自动生成了整个项目。”——AI 只用于辅助检索、补全和叙事发散，需求拆解、整合和验证由团队完成。
- “已达到生产可用。”——当前是课程项目，仍缺少完整测试、部署和安全加固。
- “公开仓库就是完整参赛作品。”——媒体资源未公开，仓库是核心代码归档。
- “项目运行时接入了 AI。”——AI 用于开发辅助，公开运行时代码不调用模型。
