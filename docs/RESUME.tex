\datedsubsection{\textbf{奇域梦幻漫游录——多章节互动视觉小说}}{2025.07}
\textbf{项目技术}：HTML、CSS、JavaScript、Web Audio API、Node.js、Express、MySQL、JWT、Cursor\\
\textbf{项目背景}：围绕《爱丽丝梦游仙境》设计多章节互动叙事，以剧情分支、章节小游戏和多结局增强用户参与感。\\
\textbf{核心工作}：负责第五章前端交互、音频接入与剧情脚本，实现对话状态推进、分支选择、角色状态反馈和多结局；与王智龙协作完成 Express 后端及 MySQL 数据库，参与 JWT 鉴权、成就/音频/道具接口和前后端联调；使用 Cursor 辅助编码与技术调研，并与美术成员完成交互场景落地。\\
\textbf{项目成果}：获全国大学生数字媒体科技作品及创意竞赛江苏赛区三等奖；完成五章节流程、剧情小游戏及账户、成就和道具等功能，整理核心代码仓库并完成配置外置、SQL统一和4项基础测试；公开版不含媒体资源。\\
